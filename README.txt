WEBSITE PROFIL BISNIS PREMIUM — VELORA

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder paket_spesial_premium.
3. Klik dua kali index.html untuk melihat website di browser.
4. Pastikan koneksi internet aktif agar foto contoh dan font Google dapat dimuat.

BAGIAN YANG TERMASUK
- Beranda / landing page
- Layanan
- Kontak dan tombol WhatsApp
- Lokasi + tautan Google Maps
- Galeri produk / portofolio
- Foto testimoni pelanggan
- Profil bisnis / tentang kami
- Desain responsif untuk HP dan desktop

CARA MENGGANTI FOTO
1. Arahkan mouse ke foto. Di HP, tombol "Ganti foto" biasanya terlihat.
2. Klik "Ganti foto" dan pilih gambar dari komputer/HP.
3. Foto akan langsung berubah sebagai pratinjau di browser.
4. Untuk membuat perubahan permanen bagi semua pengunjung, ganti URL gambar di index.html dengan nama file gambar milik Anda, lalu simpan gambar itu di folder assets. Contoh: src="assets/foto-produk-1.jpg".
   Catatan: memilih foto lewat tombol hanya pratinjau di browser saat ini, tidak otomatis mengubah file website atau menyimpan gambar ke hosting.

CARA MENGUBAH TEKS
- Banyak judul, deskripsi, nama, dan informasi kontak dapat diklik lalu diedit langsung di halaman sebagai pratinjau.
- Agar perubahan tersimpan permanen, edit teks tersebut di index.html menggunakan VS Code atau Notepad, lalu simpan.

CARA MENGUBAH WHATSAPP
- Buka index.html.
- Cari https://wa.me/6281234567890 dan ganti angka tersebut dengan nomor WhatsApp Anda menggunakan kode negara tanpa tanda +, spasi, atau strip. Contoh Indonesia: 628123456789.
- Ganti juga teks nomor telepon yang terlihat pada bagian kontak.

CARA MENGUBAH NAMA BISNIS
- Cari kata VELORA / Velora di index.html dan ubah dengan nama usaha Anda.
- Ubah email, alamat, jam layanan, layanan, produk, dan testimoni sesuai informasi asli.

CATATAN
- Foto awal menggunakan gambar contoh dari Unsplash dan memerlukan internet.
- Website ini adalah template statis. Formulir pemesanan, penyimpanan data, dan panel admin belum dibuat.
